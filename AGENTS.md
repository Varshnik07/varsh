# AGENTS.md

Personal website (Astro + React + Tailwind). Structure mirrors
`oogway-labs/oogwaylabs-com` minus the marketing/SEO tooling that's
specific to that site.

- `src/pages/` — routes
- `src/layouts/` — shared page shells
- `src/views/` — top-level page components (React, mounted via `client:load`)
- `src/components/` — reusable pieces
- `src/data/` — content (reading list, projects, etc.)
- `src/lib/` — helpers

No content or design has been built yet — this is scaffold only.
